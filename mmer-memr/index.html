MEMR vs MMER policy comparison

Comparing two decision rules under uncertainty over games, parameterized by safe-action payoff c and prior weight p1.

Setup: Two games with swapped specialist actions and a universally safe action paying c.
Non-uniqueness region: The MEMR objective is linear in a1 with slope (p2 − p1). Near p1 = p2, this slope is nearly zero, so the shaded band shows the full set of optimal a1 values — all achieving virtually the same regret. The solid line shows the extreme-point optimum, which jumps discontinuously at p1 = 0.50. This is a genuine LP degeneracy, not a numerical artifact.
